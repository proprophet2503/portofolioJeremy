About

I study Artificial Intelligence Engineering at Institut Teknologi Sepuluh Nopember in Surabaya, Indonesia. Most of my research applies machine learning to health: tuberculosis screening from cough audio, 3D lung reconstruction from plain X-rays, EEG screening for ALS and kidney cyst segmentation.

Alongside the medical work I build generative models for speech, train spiking neural networks without a framework, and have maintained the backend that serves LLM inference for a production product. I also teach as a teaching assistant for Probability and Statistics, Machine Learning and Data Mining.

Research interests

  • Physics-informed inverse problems. Reconstruction from measurements that do not determine the answer on their own. Encoding the forward physics into the loss is what makes an underdetermined problem trainable at all.
  • Generative model geometry. Score-based diffusion, flow matching and continuous normalizing flows: what path the model takes from noise to data, and what that path costs at sampling time.
  • Models that have to run. LLM inference backends, request routing and failover across providers, and clinical pipelines handed to people who did not write them.

Physics-Informed 3D Lung Reconstruction

Deep Learning Researcher · Diagnostic and Prognostic Lab, ITS · 04/2026 to present · TB Active Case Finding programme

Highlights

  • A coordinate network in the Neural Attenuation Field style represents the volume, instead of a discrete voxel grid.
  • The Beer-Lambert law is the forward operator, so the training loss is a physics residual against measured projections.
  • Ray sampling and line integrals run inside the training loop for AP, PA and lateral geometry.

Tags: PINN, Neural Attenuation Fields, Beer-Lambert, sparse-view CT, PyTorch

Summary

Reconstructing a 3D CT volume from three plain X-rays, so tuberculosis screening does not require CT access. Three projections do not determine a volume, so the forward physics has to carry the rest.

The next target is TB cavity segmentation on the reconstructed volume, which is the clinically useful output. The work is part of a wider TB detection and diagnostic programme.

AVID-MM: Identity Under Missing Modality

Lead Deep Learning Researcher · POLY-SIM 2026 Grand Challenge · 04/2026 to 07/2026

Repository on GitHub

Highlights

  • ECAPA-TDNN voice embeddings and a pretrained face backbone, projected into one shared identity space.
  • Modality dropout during training, so the shared space stays aligned when either branch is absent at inference.
  • A dual-head AAM-Softmax objective keeps identity clusters separable across languages.

Tags: ECAPA-TDNN, AAM-Softmax, modality dropout, multimodal, PyTorch

Results: POLY_1 accuracy from 59% to 93%+, validated in all three input states

Summary

Cross-modal speaker verification that still works when a modality goes missing. Real multilingual footage loses the audio or loses the face, and a system that only works on clean pairs is not deployable.

I led the implementation, from data handling to the evaluation harness for the challenge setup, and validated inference in all three input states: both modalities, audio only and visual only.

Neuromorphic Vision Without an SNN Framework

Research Assistant · Avalon AI · 04/2026 to 06/2026

Highlights

  • Izhikevich neuron dynamics with temporal encoding for event-based image classification.
  • Custom surrogate gradients in the backward pass make the non-differentiable spiking nonlinearity trainable.
  • The full stack is written from scratch: temporal encoders, spike-based layers and autograd functions, with no SNN library.

Tags: spiking neural networks, surrogate gradients, Izhikevich, custom autograd, PyTorch

Results: 76.6% accuracy on N-MNIST, with no SNN library

Summary

A spiking network trained end to end with nothing but PyTorch autograd. The spike function has zero derivative almost everywhere, so the whole problem is constructing a gradient path that does not exist by default.

The surrogate choice is pluggable, so the backward pass can be swapped without touching the forward model. The from-scratch pipeline reached 76.6% accuracy on N-MNIST.

TB Cough Screening From Acoustics

Machine Learning Developer · Diagnostic and Prognostic Lab, ITS · 08/2025 to present

Repository on GitHub

Highlights

  • Energy-based segmentation cuts each cough out of a noisy recording before any feature is computed.
  • 13 MFCCs with delta and delta-delta coefficients, 39 features per frame from 40 mel bands.
  • A two-layer LSTM reads the frame sequence, so the decision uses the temporal shape of the cough.

Tags: LSTM, MFCC, signal processing, PyTorch

Results: F1 0.89 on 449 held-out recordings; 1st Place and Best Scientific Paper, National Electrolympic UPNVJ 2025

Summary

A screening tool that classifies cough audio for TB indication, built for settings where a lab test is the bottleneck. It is positioned as triage, not diagnosis: the output is a referral signal.

Trained on 2,244 recordings from two datasets. The best configuration reached about 90% accuracy and an F1-score of 0.89 on 449 held-out recordings. The methodology won 1st Place and Best Scientific Paper at the National Electrolympic UPNVJ 2025.

SwaraTTS: Latent Flow Matching for Speech

Deep Learning Researcher · Avalon AI x RISTEK UI, Diffusion and Flow Matching Division · 02/2026 to present

Highlights

  • Score-based diffusion and latent flow matching shape the generative trajectory of speech.
  • Continuous normalizing flows compared against diffusion on sampling efficiency, since a straight path needs far fewer function evaluations than a curved stochastic one.
  • The ODE solver step budget is exposed as a tunable in the PyTorch sampling code, rather than baked in.

Tags: flow matching, score-based diffusion, CNF, neural TTS, PyTorch

Summary

A low-latency neural speech synthesiser built with a research team. The core question is which generative paradigm gets acceptable audio in the fewest solver steps.

The work happens in latent space rather than waveform space to keep the transport problem tractable, and the generative module stays swappable behind a fixed interface so the team can compare methods.

EEG Screening for ALS

AI Researcher · Pusat Studi Kecerdasan Artifisial, ITS · 01/2026 to present

Repository on GitHub

Highlights

  • Recordings segmented by task: resting, thinking and typing.
  • Mean absolute value, variance and standard deviation computed per subband, from delta through gamma.
  • A backend processing pipeline built for a team of four, so the signal scripts run inside a working web application.

Tags: EEG, EDF, feature engineering, scikit-learn, Python

Summary

An end-to-end signal pipeline that separates ALS subjects from controls across 1,809 clinical EDF recordings. Most of the work is in the feature stage: what you extract per band and per task decides what the classifier can see.

Classifiers trained on the resulting feature matrix provide diagnostic support, with preprocessing run over specific channels, bands and subbands of the full EDF corpus.
