What I work on

Three threads, one habit: implement the method from scratch before trusting a library wrapper around it.

/01

Generative model geometry

Score-based diffusion, flow matching, and continuous normalizing flows. The question I care about is what path the model takes from noise to data, and what that path costs at sampling time.

/02

Physics-informed inverse problems

Reconstruction from measurements that do not determine the answer on their own. Encoding the forward physics into the loss is what makes an underdetermined problem trainable at all.

SwaraTTS: latent flow matching for speech

Deep Learning Researcher Avalon AI x RISTEK UI 02/2026 to present
Diffusion and Flow Matching Division

A low-latency neural speech synthesiser built with a research team. The core question is which generative paradigm gets acceptable audio in the fewest solver steps, so the work sits on the trade-off between continuous normalizing flows and diffusion.

AI research

  • Implemented score-based diffusion and latent flow matching to shape the generative trajectory of speech.
  • Compared CNF against diffusion paradigms on sampling efficiency, since a straight probability path needs far fewer function evaluations than a curved stochastic one.
  • Worked in latent space rather than waveform space to keep the transport problem tractable.

Engineering

  • Training and sampling code in PyTorch, with the ODE solver step budget exposed as a tunable rather than baked in.
  • Coordinated across a multidisciplinary team, keeping the generative module swappable behind a fixed interface.

AVID-MM: identity under missing modality

Lead Deep Learning Researcher POLY-SIM 2026 Grand Challenge 04/2026 to present
Repository

Cross-modal speaker verification that still works when a modality goes missing. Real multilingual footage loses audio or loses the face, and a system that only works on clean pairs is not deployable.

AI research

  • Built a multimodal embedding pipeline: ECAPA-TDNN for voice, a pretrained face backbone for vision, projected into one shared identity space.
  • Trained with modality dropout so the shared space stays aligned when either branch is absent at inference.
  • Dual-head AAM-Softmax objective to keep identity clusters separable across languages.

Engineering

  • Led the implementation, from data handling through the evaluation harness for the challenge setup.
  • Inference path validated under all three input states: both modalities, audio only, visual only.

Physics-informed 3D lung reconstruction

Deep Learning Researcher Diagnostic and Prognostic Lab 04/2026 to present
TB Active Case Finding programme

Reconstructing a 3D CT volume from three plain X-rays, so tuberculosis screening does not require CT access. Three projections do not determine a volume, so the forward physics has to carry the rest.

AI research

  • Parameterised the attenuation field with a coordinate network in the Neural Attenuation Field style, rather than a discrete voxel grid.
  • Encoded the Beer-Lambert law as the forward operator, so the training loss is a physics residual against measured projections.
  • Targeting TB cavity segmentation on the reconstructed volume, which is the clinically useful output.

Engineering

  • Ray sampling and line-integral computation written to run inside the training loop for triplanar AP, PA, and lateral geometry.
  • Built as part of a wider clinical detection and diagnostic pipeline, alongside clinicians at Rumah Sakit Universitas Airlangga.

Neuromorphic vision, no SNN framework

Research Assistant Avalon AI 04/2026 to present
N-MNIST

A spiking network trained end to end with nothing but PyTorch autograd. The spike function has zero derivative almost everywhere, so the entire problem is constructing a gradient path that does not exist by default.

AI research

  • Izhikevich neuron dynamics with temporal encoding for event-based image classification.
  • Custom surrogate gradient functions substituted into the backward pass so the non-differentiable spiking nonlinearity becomes trainable.
  • Reached 76.6% accuracy on N-MNIST with the from-scratch pipeline.

Engineering

  • Wrote the full training stack: temporal encoders, spike-based layers, and custom autograd functions, with no external SNN library.
  • Kept the surrogate choice pluggable so the backward pass can be swapped without touching the forward model.

TB cough screening from acoustics

Machine Learning Developer Multimodal TB Diagnostic System 08/2025 to present
Repository 1st place, National Electrolympic UPNVJ

A screening tool that classifies cough audio for TB indication. Built for settings where a lab test is the bottleneck, so the model has to run on recordings people can actually produce.

AI research

  • Acoustic front end on MFCC and log-mel features, framed at 25 ms with a 10 ms hop.
  • LSTM over the frame sequence, so the decision uses the temporal shape of the cough rather than a single pooled frame.
  • Presented the methodology to an academic expert panel, which is where the scientific paper award came from.

Engineering

  • End-to-end path from raw audio through feature extraction to a class posterior, deployed for clinical-environment screening.
  • Positioned explicitly as triage, not diagnosis, with the output framed as a referral signal.

EEG screening for ALS

AI Researcher Pusat Studi Kecerdasan Artifisial, ITS 01/2026 to present
Repository

An end-to-end signal pipeline separating ALS subjects from controls across 1,809 clinical EDF recordings. Most of the work is in the feature stage: what you extract per band and per task decides what the classifier can see.

AI research

  • Feature extraction per segmented task (resting, thinking, typing) across delta through gamma subbands.
  • Time-domain descriptors computed per band: mean absolute value, variance, and standard deviation.
  • Trained and evaluated classifiers on the resulting feature matrix for diagnostic support.

Engineering

  • Preprocessing across specific channels, frequency bands, and subbands, run over the full EDF corpus.
  • Built the backend processing pipeline for a team of four so the signal scripts drop into a working web application.
